# Probabilidad de impacto

Usaría:

\[ \boxed{ P_{impacto} = 0.80 + 0.5 \left( \frac{Precisión-Evasión} {Precisión+Evasión+100} \right) } \]

con:

\[ \boxed{ 10\% \le P_{impacto} \le 95\% } \]

El valor importante es el **80% base**.

Si dos personajes tienen exactamente la misma Precisión y Evasión:

\[ Precisión=70 \]\[ Evasión=70 \]

entonces:

\[ P=0.80 \]

Es decir:

\[ \boxed{80\%} \]
